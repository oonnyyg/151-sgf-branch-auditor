# sgf-branch-auditor

离线 SGF 复盘审核工具：检查棋谱中每一条变化分支的落子是否合法。
只使用 Go 标准库，不提供棋力评价，也不提供图形界面。

## 构建与使用

```sh
go build .
./sgf-branch-audit [-json] [-query N] <file.sgf>
```

- 默认输出文本报告：每个节点一行，含前序编号、父编号、着手、合法性与累计提子。
- `-json` 输出 JSON 报告（同样的字段，供程序消费）。
- `-query N` 打印编号为 N 的节点棋盘（`X` 黑 / `O` 白 / `.` 空）与双方累计提子。

## 输入约定

- 读取单棵 SGF FF[4] 棋树，棋种为围棋（`GM[1]`），方形棋盘 `SZ` 边长 2–19；
  非方形（`SZ[w:h]`）明确拒绝。
- 支持根属性（`FF`/`GM`/`SZ` 等）、黑白着手 `B`/`W` 与注释 `C`；
  属性值中的反斜杠转义与软换行按 FF[4] 处理。
- 未知普通属性跳过；`AB`/`AW`/`AE`（设置棋子）与 `PL`（指定行棋方）明确拒绝，
  不假装已支持。
- 结构解析失败（括号不配对、属性无值等）则整文件拒绝。

## 规则

- 根节点为空棋盘且黑先，之后严格轮流；空着手 `B[]`/`W[]` 表示停着。
- 坐标为小写字母（`aa` 为左上角）；越界或落在已占用交点均为非法。
- 先提掉相邻无气的对方棋块（可一手提多块），再检查己方气，禁止自杀。
- 简单劫：非停着落子后的棋盘不得等于对手上一手之前的棋盘；
  停着始终合法并参与历史推进。不额外实施全局同形禁着。

## 分支语义

- 每条变化从父节点的完整状态独立继续：棋盘、行棋方、提子数与劫历史
  在兄弟分支间不共享任何可变状态。
- 节点非法时保留原因，其所有后代标记为“无法复盘”（无棋盘可查），
  其他分支继续正常审核。
- 规则错误只保留合法前缀，不自动改色、不删棋修复。

## 不处理的内容

- 终局计分与数子：本工具只审核落子合法性。
- 让子：`AB` 等设置属性被拒绝，让子棋谱无法审核。
- 连续停着不自动截断棋谱：停着只是一手合法着法，后续节点照常审核。

## 测试

```sh
go test ./...
```

覆盖：多块提子、自杀禁止、简单劫（含停着后劫争解除）、
分支隔离（棋盘/提子/劫历史不串）、非法节点的后代标记、
转义解析、前序编号与父编号。
