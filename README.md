# SGF Branch Auditor

离线 SGF（FF[4]，围棋）复盘审核工具，仅使用 Go 标准库。逐节点检查每条
变化分支的落子是否合法；不提供棋力评价，也不提供图形界面。

## 构建与使用

```sh
go build -o sgf-audit .
./sgf-audit game.sgf          # 文本报告：每节点前序编号、父编号、合法性
./sgf-audit -json game.sgf    # JSON 报告
./sgf-audit -query 12 game.sgf  # 按编号查看棋盘与双方累计提子
```

## 支持范围

- 单棵 SGF FF[4] 棋树，GM[1]（围棋），方形棋盘 SZ 2–19（缺省 19）。
- 根节点必须为空棋盘、黑先；根节点不得含着手。
- 支持 `B`/`W` 着手（小写坐标，空值 `B[]` 为停着）与 `C` 注释。
- 属性值按 SGF 规范处理反斜杠转义与软换行；容忍 UTF-8 BOM。
- 未知普通属性直接跳过。
- 明确拒绝（不假装支持）：`AB`/`AW`/`AE`（设置棋子）、`PL`（指定行棋方）、
  `HA`（让子）。出现在根节点则整文件拒绝，出现在后续节点则该节点判非法。

## 规则

- 轮流着棋，黑先；越界、占用已占交点均非法。
- 先提掉相邻无气的对方棋块，再检查己方棋块气；自杀禁着。
- 简单劫：非停着落子后的棋盘不得等于对手上一手之前的棋盘。
  停着始终合法并推进劫历史；不实施全局同形禁着。
- 不处理终局计分与让子；连续停着不会自动截断棋谱。

## 分支语义

- 每条变化从父节点的完整状态（棋盘、行棋方、累计提子、劫历史）独立
  继续，兄弟分支间不共享任何可变状态。
- 节点非法时保留原因，其所有后代标记为“无法复盘”，其余分支照常审核。
- 结构解析失败（含根属性非法）整文件拒绝；规则错误保留合法前缀，
  不自动改色或删棋修复。

## 测试

```sh
go test ./...
```

覆盖：多块同时提子、简单劫（含停着后合法回提）、分支隔离、自杀/占用/
越界、转义与未知属性、设置属性拒绝、结构错误整文件拒绝。
